# Pi Plugins documentation

Independent static Astro/Starlight site. Production canonical: https://pi-plugins.vercel.app.

```sh
cd site
npm ci
npm run check
npm run build
npm run dev
```

Use Node.js 22.12 or newer. On the maintainer’s machine, dependency changes use `npm-cooldown -- npm install`; never bypass the configured release-age policy. The lockfile belongs to this directory, not a root workspace.

- `check`: compares the 19 reference pages/catalog entries to the root suite manifest; validates frontmatter, minimum reference structure, selection paths and local documentation links; then runs Astro diagnostics.
- `build`: emits static `dist/`, builds the Pagefind search index, then checks rendered internal links/fragments, assets, canonical URLs, metadata and search output.
- `dev`: local development server. Full search is generated by the production build.
- `preview`: serves the built output locally.

No backend adapter, credentials, model requests or runtime plugin imports are used. Fonts and search are served locally. External links are not fetched by checks.

## Authoring

Public pages live in `src/content/docs/`. Per-plugin reference filenames and `plugin` frontmatter must match `packages/<name>`. The catalog and navigation groups live in `src/data/plugins.mjs`. Selected-entry examples use `packages/<name>/src/index.ts`, without a leading `./`.

Keep requirements and optional integrations explicit. The suite has one Git ref and loads all entries unless filtered. Do not present other harness ports as supported by this installation. Illustrations must be labeled as examples.

The root repository owns CI and deployment. This package only produces static files; it does not configure or deploy a Vercel project.
