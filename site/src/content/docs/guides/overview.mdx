Pi Plugins is Spencer Boucher’s personal collection of extensions for [Pi](https://pi.dev). The collection focuses on the working session: keeping background tasks visible, making decisions deliberately, understanding context, and improving the terminal.

This site documents the **Pi suite**. It does not install a different agent or promise support for other harnesses. Related projects are just that: [related projects](/about/).

## Choose a starting point

- **A quieter terminal:** try [prose width](/plugins/pi-prose-width/), the [copy picker](/plugins/pi-copy/), or [picker navigation](/plugins/pi-select-nav/). They do not require the rest of the suite.
- **Long-running development:** use [background jobs](/plugins/pi-bg/) and [subagents](/plugins/pi-subagents/), with optional shared activities including notebooks, planners and Herdr children.
- **Changes worth thinking through:** use [plan mode](/plugins/pi-plan-mode/), then review actual file changes with [diff review](/plugins/pi-diff-review/).
- **A large conversation:** start with [cache guard](/plugins/pi-cache-guard/)'s warnings and clock. Add classifier-assisted features only after reviewing their cost and data flow.

[Install and select](/guides/install/) explains how to enable a subset. A plain suite install loads all 26 entries. Each entry can be disabled independently; versions are pinned together.

**Learn the keys:** the [task-oriented keymap](/guides/keyboard/) separates native transcript navigation/search, suite Vim/chords, dialog focus and optional personal bindings. Ctrl+L view clearing and Shift+Tab permissions need explicit stock-action remaps—not automatic overrides.

## What this collection is not

The tool gate is not an operating-system sandbox. Cache estimates are not billing statements. A read-only planner policy is not a guarantee about tools you explicitly trust. Terminal compatibility patches may need revisiting when Pi or your multiplexer changes.

Read [requirements and costs](/guides/requirements/) before turning on integrations, and [troubleshooting](/guides/troubleshooting/) if another extension owns the same command, footer or editor.
